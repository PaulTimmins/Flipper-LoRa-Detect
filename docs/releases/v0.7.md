# LoRa Detect v0.7 — experimental prerelease

Detect, decode, and experimentally transmit MeshCore Public and Meshtastic LongFast traffic using a stock Flipper Zero's internal CC1101. No external LoRa radio or custom firmware is required.

## Install

Download **lora_detect.fap** below. Using qFlipper File Manager, copy it to **SD Card → apps → Sub-GHz**, then open **Apps → Sub-GHz → LoRa Detect**. No compiler or Codex needed. See the attached INSTALL.md for full instructions.

Built and device-tested with **official firmware 1.4.3 / API 87.1 / target f7**. Other firmware combinations are untested. Existing settings and logs are preserved on update.

## Included

- Background decoding, RSSI, tentative advertisement names, public-channel chat, and phone-readable/hex logs.
- Numbered or keyboard-composed Public/LongFast messages and local discovery queries.
- A chat keyboard with explicit Space, punctuation, case, Del, and Done controls.
- Saved channel, scanning, route, sound, backlight, logging, and decoder settings.
- MeshCore hop-hash width of 1/2/3 bytes, default 2.
- A decoder-memory fix: lossless packed captures save 12 KB; workspace allocation retries instead of leaving decoding permanently unavailable.

## Validation and limits

Host tests cover capture packing, PHY decoding, protocol parsing, independent public-channel crypto, and coherent recovery of the actual transmit waveform, including maximum-length messages. Device tests verify the composer, saved settings, and decoding after transmission. Earlier SDR captures and real mesh nodes confirmed both protocols' transmitted text; a native LongFast rebroadcast was also captured.

Transmission is experimental OOK-sideband synthesis with mirrored components and harmonics, fixed US profiles, nominal -10 dBm PA, and no measured emissions-compliance result. The documented temporary US-region carrier exception is restored immediately; no persistent region file is modified. Queries are local; messages can use the selected Local/Flood route. A completed send is not an acknowledgment.

Receive sensitivity, decode speed, and simultaneous-packet capture are limited. CRC does not authenticate the sender; on-device advert signatures are not verified. Raw RF captures and private device logs are not included in this release.
