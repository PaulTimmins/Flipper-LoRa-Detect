# LoRa Detect v0.8 — names and persistent identities

Download **lora_detect.fap** below and copy it with qFlipper to **SD Card → apps → Sub-GHz**, replacing the old app while it is closed. No compiler is needed. Built for **official firmware 1.4.3 / API 87.1 / target f7**. Existing settings and logs are preserved.

## Changes

- **Hold OK → Name** opens the chat keyboard to set a saved sender name for both protocols. Names can contain 1–16 printable ASCII characters, without a colon or leading/trailing spaces.
- First launch generates independent MeshCore Ed25519 and Meshtastic X25519 keypairs using the Flipper hardware RNG. Keys persist across renames and restarts. Existing valid MT node IDs are preserved; new installations derive their MT node number from the device MAC.
- MeshCore Public messages include the saved name. Meshtastic shares it through the local NodeInfo query, with private messaging marked unavailable.
- Copying initialized identity data to a different Flipper generates new identities for that device. A corrupt identity file or failed save blocks TX instead of using a shared fallback.
- Reduced the packed capture buffer to 16 KB to retain decoder headroom with the added crypto code. Longer MT transmissions use a temporary 2 KB extension, freed before RX resumes.

## Validation

The full host suite passes, including independent Ed25519/X25519 checks, packet crypto, and maximum-length waveform recovery. Device checks verified first-launch key generation, preservation of the existing MT ID, name editing and persistence across restart, unchanged keys after rename, and a successful MT discovery transmission followed by active decoding. The user also confirmed the updated app works. Cross-device SD-card migration was not physically tested.

## Limits

The identity keys are saved for future features: signed MeshCore adverts and private messaging are **not implemented**. Public chats still use the standard shared channel keys, and Public sender names are not authenticated. Keep `identity.bin` private; do not distribute device data with the app.

Transmission remains experimental internal-CC1101 OOK-sideband synthesis, with fixed US profiles, mirrored components and harmonics, nominal -10 dBm PA, and no measured emissions-compliance result. A completed send is not an acknowledgment. Receive sensitivity, decode speed, and simultaneous-packet capture remain limited. See INSTALL.md and the repository README for details.
