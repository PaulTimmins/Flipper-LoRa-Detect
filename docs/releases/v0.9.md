# LoRa Detect v0.9 — firmware 1.5.1 and MeshCore hashtags

Choose the app file that matches your **official Flipper Zero firmware**:

- **1.5.1:** `lora_detect-1.5.1.fap`
- **1.4.3:** `lora_detect-1.4.3.fap`

Copy the selected file to **SD Card → apps → Sub-GHz** with qFlipper while LoRa Detect is closed. Remove or replace the old `lora_detect.fap` if present. The filename may include the firmware version. Existing settings, identity, and logs are preserved. See INSTALL.md for full instructions.

Flipper external apps include a firmware API version. The loader rejects an older app when a firmware update changes the major API version. Each file here is compiled against its matching official SDK. Future breaking API updates may require another build.

**Hold OK → MC hashtag** now accepts one optional MeshCore hashtag channel. It starts empty and can be cleared again. Enter `#pikachu-messages` to decode that channel alongside the existing Public channel. The key is derived from the exact hashtag, and the channel hash and two-byte message MAC are checked before text is shown. The phone log labels the hashtag and keeps the sender marked unverified. The setting listens and decodes; it does not add hashtag transmission. Hashtag channels are guessable and should be treated as public.

Host tests include an independent `#pikachu-messages` key/hash and encrypted packet fixture, including wrong hash and MAC rejection. Both official SDK builds and the host regression suite run in CI. The 1.5.1 build has not yet had an on-device test in this workspace; the 1.4.3 version of the app was device-tested previously. Reception and internal-radio transmission remain experimental. A completed send is not an acknowledgment.
